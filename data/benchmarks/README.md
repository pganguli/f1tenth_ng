# Local Benchmark Artifacts

This directory stores generated benchmark outputs for the `feature-alpha-coins`
workflow.

Tracked code should write here, but generated artifacts should remain local and
untracked. The canonical local stems are:

- `single_tier_paper_strategies_10maps*`
- `single_tier_oracle_baseline_10maps*`
- `multi_tier_cloud_benchmark_10maps_corrected*`
- `paper_figures_10maps_curated/`

Keep only the minimum active artifacts you still need for analysis. Delete stale
sanity runs, superseded figure exports, and macOS metadata files such as
`.DS_Store`.
