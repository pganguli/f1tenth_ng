\title{Age-Decay Sanity Study Report}
\maketitle

\section{Goal}
This report documents a fast sanity-check of anchored age decay using a strict non-train boundary and max CTE as the primary metric.

\section{Setup}
Train maps: Austin, Budapest, Melbourne, Sakhir, Zandvoort.\\
Eval maps: Nuerburgring, Sochi, Spa.\\
Cloud latency: 5.\\
Lambda grid: 0, 1, 4, 16, 64.\\
Selection metric: max\_cte.\\
Boundary hit: True.\\
Selected lambda: $\lambda^* = 0.0$.

\section{Commands Run}
\begin{itemize}[leftmargin=*]
